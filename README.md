# Seletor de acabamentos

Comparador visual de materiais para cozinha e sacada, com 18 combinações, três vistas principais completas e ângulos extras.

## Usar

Abra `index.html` no navegador, mantendo a pasta `assets` ao lado. Não exige instalação, compilação ou conexão com a internet. Também pode ser servido como site estático.

- Selecione as bancadas, os tampos e os revestimentos.
- Alterne entre cozinha de frente, cozinha pelo fogão e sacada de frente.
- Compare duas opções e amplie ou baixe as fotos.

As 50 imagens PNG estão em `assets/`. Fotos frontais são reutilizadas quando apenas um material fora do enquadramento muda. As imagens são simulações: cores, veios e pequenos detalhes podem variar.
